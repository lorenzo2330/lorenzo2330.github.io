# Struttura del sito

| Cosa vuoi modificare | File |
|---|---|
| Bio, soft skills, competenze | `index.html` |
| Elenco progetti (card) | `projects.html` |
| Un singolo progetto (testo, video, link) | `projects/<nome>.html` |
| Contatti | `contact.html` |
| Menu, tema chiaro/scuro, modale CV, toast | `assets/js/site.js` |
| Colori e font di Tailwind | `assets/js/tailwind-config.js` |
| CSS personalizzato | `assets/css/style.css` |
| GIF dei progetti | `media/` (`gep-boss.gif`, `arkanoid-ai.gif`, `paopao-bot.gif`, `flipper.gif`, `buildfailed.gif`) |
| CV | `assets/CV_Lorenzo_DAmbrosio.pdf` |

Aggiungere un progetto: copia un file in `projects/`, cambia testi e `id` (p1, p2...), poi aggiungi la card in `projects.html`.

Foto profilo: `assets/propic.jpg`. Tesi: `assets/tesi-muse-explorl.pdf`. GIF aggiuntive: `hexgrid.gif`, `mask-museum.gif`, `muse-explorl.gif`, `dimora-concordia.gif`.
