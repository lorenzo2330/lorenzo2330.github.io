Unreal Engine 5.8 · AI Gameplay

Simple Platform (Boss AI con State Tree)

UE 5.8 State Tree AIPerception C++ / Blueprint

Platformer in Unreal Engine con monete, nemici pattuglianti e un Boss controllato interamente da uno State Tree reattivo integrato con il sistema di percezione sensoriale.

Anteprima Dimostrativa

Feature AI Principali

  • Percezione Visiva L'AIC_Enemy traduce la vista in Gameplay Tags leggeri per disaccoppiare percezione e decisione.
  • Memoria del Target Gestione del timer MemoryDuration per l'ispezione dell'ultima posizione nota prima del pattugliamento.
  • Ciclo Combattimento Fasi d'attacco intervallate da stati di vulnerabilità ed attesa a durata variabile per evitare meccanicità.
Dettagli Tecnici & Architettura Pipeline

Pipeline completa: Percezione (AIC_Enemy) → Eventi Tags (AI.Event.Attacking, AI.Event.Lost) → Decisione State Tree (ST_Enemy) → Azioni (Move To, Attack Task, Vulnerability Timer).

  • Gerarchia Stati: Idle (Pattuglia/Wander), Investigate, Attacking (Inseguimento, Attacco, Vulnerabilità). L'uso degli stati raggruppati evita il sovraccarico di transizioni.
  • Motivazione State Tree: Garantisce transizioni esplicite ed atomiche guidate da eventi, perfetto per Boss con fasi ben definite rispetto a un Behavior Tree continuo.
  • Limiti & Sviluppi: Percezione limitata alla vista. Sviluppo futuro: selezione attacchi mediante Utility Considerations (cooldown, distanza, priorità).
